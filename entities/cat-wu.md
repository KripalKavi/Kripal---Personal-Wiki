# Cat Wu

## Role / Background

Head of Product for Claude Code and Cowork at Anthropic. Background: software engineer for several years → VC briefly → Anthropic. Former Scale AI employee (worked there when the company was ~20 people; credits Scale for instilling "just do things" / no-boundary operating culture). Nearly all PMs on her team have engineering backgrounds or actively ship code on Claude Code; designers are former front-end engineers.

Co-leads Claude Code with Boris Cherny. Division of labor: Boris sets the 3–6 month AGI-forward vision and technical direction; Cat Wu owns the path from current state to that vision and all cross-functional execution (marketing, sales, finance, capacity). ~80% overlap in perspective; each independently drives the remaining 20% where they care more than the other.

Manages a team of ~30–40 PMs across: Research PM, Claude Developer Platform, Claude Code/Cowork, Enterprise, and Growth.

## Key Ideas

**The PM role has fundamentally shifted to velocity**: Less multi-quarter partner alignment; more "how do we get something in users' hands this week?" Three mechanisms: clear goals (specify user + problem + use case), Research Preview labeling to lower launch commitment, and PM-built evergreen cross-functional launch infrastructure that lets engineers ship without friction.

**[Right amount of AGI-pilled](../concepts/right-amount-agi-pilled.md)**: The hardest PM skill is calibrating product design to current model capability, not hypothetical superintelligence. Building for super-AGI is easy — just a text box. Building for today's model — guiding users to the golden path, patching weaknesses in the product surface — is rare and hard.

**[Model eats the harness](../concepts/model-eats-the-harness.md)**: Every new model launch is an opportunity to remove scaffolding that compensated for prior weaknesses. The Claude Code to-do list went from essential (earlier models would abandon tasks) to cosmetic (Opus 4+ does it naturally). Systematic practice: read the entire system prompt at each model launch, remove what's no longer needed.

**Product taste is the scarce skill**: As code gets cheaper, deciding what to build matters more than building it. Taste — knowing which of 10,000 GitHub issues is worth shipping — can come from any background but is rare. Engineering background is currently useful for intuitions about implementation cost, but Cat Wu hedges: valued skill sets change every few months.

**Mission as organizational infrastructure**: Teams willing to sacrifice their own OKRs for the company mission creates a fast-decision mechanism unavailable at most companies. "If Claude Code failed but Anthropic succeeded, I would be extremely happy." This willingness enables cross-org decisions that would otherwise take months of stakeholder management.

**95% automation is not an automation**: If it doesn't work 100% of the time, it still requires supervision. The last 5–10% is what makes the leverage real. Push automations to 100% before trusting them.

Cat Wu is the most senior PM voice directly shaping the products that are redefining software development.
