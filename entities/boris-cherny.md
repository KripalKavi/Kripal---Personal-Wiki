# Boris Cherny

## Role / Background

Creator and Head of Claude Code at Anthropic. Built Claude Code from a terminal prototype into a product that now accounts for 4% of public GitHub commits. Previously explored Cursor (a competing AI coding tool) before returning to Anthropic. Engineer-turned-product-builder with deep roots in developer tooling.

---

## Key Ideas

- "Coding is solved" — the fundamental problem of translating human intent into executable code has been addressed by AI
- Latent demand discovery as a product methodology: find what users are already attempting and failing at, rather than specifying new behaviors top-down
- Underfunded teams with unlimited AI token access build better AI products than well-funded teams with token constraints
