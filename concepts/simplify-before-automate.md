# Simplify Before You Automate

## Definition

Automation should be the final step in a process redesign: first question requirements, delete unnecessary work, simplify and optimize what remains, accelerate the validated flow, and only then automate it.

## Why It Matters

Automation freezes assumptions into systems and scales whatever process it receives. If the process is wrong, automation makes the wrong answer faster, more expensive, and harder to change.

## Examples

- Tesla’s Model 3 production crisis exposed the danger of automating an immature process; manual production helped establish reality before automation was rebuilt around it.
- In Model X door assembly, observing operators directly exposed a simple jig opportunity that abstract analysis had missed.

## PM Application

Before proposing an AI agent or workflow automation, ask: What requirement can disappear? What step is merely historical? What is the smallest process that reliably produces the user outcome? Only after those questions are answered should the team optimize latency, scale, and automation.
