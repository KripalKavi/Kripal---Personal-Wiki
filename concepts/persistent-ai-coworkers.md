# Persistent AI Coworkers

## Definition

A persistent AI coworker is an AI system that keeps enough context, memory, and continuity to behave like a teammate across sessions instead of a one-off assistant in a fresh chat.

## Why It Matters

Chat is episodic. Work is ongoing. The product opportunity is to make AI durable enough to resume work, remember decisions, and coordinate with humans and other agents without forcing the user to start over every time.

That changes the product problem from "answer the question" to "keep the work alive."

## Examples

- A PM comes back to a project after two days and the agent still remembers the open tradeoffs and prior experiments.
- A team shares one workflow where different agents can pick up related tasks and the human can review the whole thread later.
- An enterprise user expects the agent to know which systems it can access, what data it already touched, and what the current objective is.

## PM Application

For Microsoft teams:

1. Design for resumption, not re-entry.
2. Make context and state durable across sessions, devices, and collaborators.
3. Treat agent-to-agent and human-to-agent collaboration as core UX, not a demo trick.
4. Build the access layer and reliability layer as part of the product, because a coworker needs permissions and systems, not just intelligence.
